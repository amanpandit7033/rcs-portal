Real-Time Delivery Report (DLR) Webhook

When carrier delivery reports (delivered, read, failed) are received, our engine forwards the JSON payload to your HTTP endpoint. Callbacks are signed with an X-Signature-SHA256 HMAC header so you can verify authenticity.

Your endpoint must return HTTP 200 within 10 seconds. Retries occur with exponential backoff on failure.

Quick API Request Example

Send a single message via curl using your generated API key:

curl -X POST "{{ request.scheme }}://{{ request.get_host }}/api/v1/messages/send/" \
  -H "Content-Type: application/json" \
  -H "apikey: <YOUR_API_KEY>" \
  -H "Idempotency-Key: req_uuid_12345" \
  -d '{
    "sender_profile_id": 1,
    "recipient": "+919876543210",
    "message_type": "PROMOTIONAL",
    "content_type": "text",
    "payload": {"text": "Hello from API!"}
  }'
